Cerebrum AI is an intelligent deep learning system designed to detect and classify brain tumors from MRI images through a web-based interface. The core of this system is a customized deep neural network built on top of the pre-trained VGG16 model, which has been fine-tuned to classify brain scans into categories such as glioma, meningioma, pituitary tumors, or no tumor (healthy). Initially, the VGG16 model is loaded with include_top=False to exclude its original classification layers, and its weights are retained from the ImageNet dataset. The image input size is configured to 128x128 pixels to match the MRI dataset. Most of the VGG16 layers are frozen to preserve the learned features, with only the last few layers made trainable to allow specialized adaptation for the MRI classification task. A new classification head is then appended, beginning with a Flatten layer, followed by Dropout to reduce overfitting, a dense layer with 128 neurons and ReLU activation, another Dropout layer, and finally a softmax layer that outputs the probability distribution across all tumor types. The entire system is deployed through a Flask-based web application that enables real-time image upload and prediction. Additionally, it generates a downloadable PDF report using FPDF, summarizing the diagnosis, confidence score, and medically relevant information. By combining transfer learning with real-time usability, Cerebrum AI brings AIassisted diagnostics closer to healthcare applications, aiming to improve early detection and empower users with reliable second-opinion tools. It is a step toward bridging medical imaging with real-time deep learning predictions, empowering both professionals and patients with instant insights into neuro health.
